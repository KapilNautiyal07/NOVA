LangGraph Guide

LangGraph is a library for building stateful, multi-actor applications with large language models. It models agents as graphs of nodes and edges.

Each node is a function that reads and updates a shared state. Conditional edges decide which node runs next, which makes routing between specialised agents explicit and testable.

Checkpointing lets a graph pause for human confirmation and resume later, a key building block for safe tool-using agents.
